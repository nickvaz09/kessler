The risk model

Meet VIGIL.

When two objects are headed for a close approach, operators receive a series of conjunction messages, each with a fresh estimate of the collision probability. VIGIL reads that series so far and predicts where the probability will finally land — so you can tell early which events will matter.

What the numbers mean. Error is the mean squared difference between the predicted and actual final probability, measured in orders of magnitude (log₁₀), so lower is better. “High-risk” events are those whose final probability was 1 in a million or higher.

Where the data comes from. VIGIL was trained on the ESA Kelvins Collision Avoidance Challenge dataset — real operator conjunction messages. We held out a random 20% of those events for testing; this is our own 80/20 split, not the competition’s hidden test set, so the figures aren’t directly comparable to the leaderboard.

How much to trust the high-risk figure. The high-risk edge is seed-sensitive: on other random splits it shrinks and can disappear, so read it as roughly on par with carry-forward. The overall improvement holds up across splits.

    How it works

    1

    Read the messages so far

    Each conjunction message carries the predicted miss distance, relative speed, time to closest approach and a collision probability. VIGIL looks at the whole sequence, not just the latest one.

    2

    Summarize the trend

    From that sequence it builds eleven simple signals — the latest probability, how fast it’s rising or falling, its peak so far, how the miss distance is changing, and how often messages are arriving.

    3

    Predict the final risk

    For events already at high risk, VIGIL deliberately trusts the latest value — that’s where carry-forward is hardest to beat. Below that, where risk usually decays, a gradient-boosted model predicts a correction to the latest probability.

    Trained on — events. Every risk number Kessler shows is stamped with the model version that produced it.

    What it can’t do

    Kessler uses honest defaults where operators would have better data. These are the limits worth knowing.

    • Screening probabilities are estimates

      Public orbit data has no uncertainty information, so screening assumes typical TLE accuracy — 300 m at epoch, growing 400 m per day — and a standard encounter-plane approximation. Good for triage, not for maneuver decisions.

    • It can’t see maneuvers coming

      Orbits are propagated with SGP4 from public elements. If an operator fires a thruster, Kessler won’t know until the next element set is published.

    • It learned from operator data

      VIGIL trained on messages with real covariances; live screening probabilities rest on the assumptions above. Treat its corrections as trend guidance, not operator-grade probabilities.
